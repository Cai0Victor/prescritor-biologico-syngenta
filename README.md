# 🌿 Prescritor e Calculadora de Biológicos Syngenta

Aplicação WebApp desenvolvida em Google Apps Script para prescrição técnica, cálculo de dosagem e volume de calda de produtos biológicos em campo.

## 🛠️ Tecnologias
- **Backend:** Google Apps Script (V8 Engine)
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **CLI Sync:** @google/clasp
- **Database:** Google Sheets (`Base_Produtos`)

## 🚀 Comandos de Desenvolvimento
- Enviar código local para o Apps Script: `clasp push`
- Abrir editor online no navegador: `clasp open-script`
- Versionar alterações no GitHub:
